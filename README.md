# 申购王 🏆

> **钉钉申购排行榜** — 导入 Excel 自动生成申购排行，让每个申请都公开透明

## 痛点

公司里总有那么几个部门或个人申购特别频繁，但谁最多、哪个部门最猛，从来没人统计过。

申购王就是干这个的——把钉钉导出的申购数据拖进去，排行榜立马出来，谁看了都得害臊 😄

> 💡 按审批编号自动去重，一条申购单多条明细只算一次，排行公平

## 功能

- 📂 **导入 Excel / CSV** — 钉钉导出数据直接拖拽，自动识别列名（支持"创建人""审批编号"等常见表头）
- 👤 **个人排行** — 按申购笔数排名，冠亚季军带称号
- 🏢 **部门排行** — 按部门汇总申购笔数和参与人数
- 📊 **数据概览** — 总笔数、申购人数、涉及部门一览
- 🎯 **趣味称号** — 申购王 / 申购达人 / 申购能手 / 王牌部门
- 🧪 **示例数据** — 没真实数据也能点"加载示例"体验
- ✨ **液态玻璃 UI** — 暗色毛玻璃风格，视觉拉满

## 使用

1. 打开 https://1994umbrella.github.io/ding-talk-rank/
2. 从钉钉后台导出申购审批数据（Excel 格式）
3. 拖拽或点击上传
4. 排行榜自动生成

### 钉钉导出路径

`钉钉管理后台 → 工作台 → 审批 → 数据导出 → 申购类审批`
